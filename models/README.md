# DDColor-T weights

DDColor-T is the only model supported by the application. Place the official checkpoint at `ddcolor_paper_tiny.bin` in this directory. The loader verifies the expected tensor structure with strict state-dict loading and reports a clear error if weights are missing or invalid.

Model: `piddnad/ddcolor_paper_tiny`, revision `fa6a961`, Apache-2.0.

Expected SHA-256: `8a1277bc90a1bfbb6d2d83933a9a6bc821931879ca93e26e4fcec12165d41fce`.

Large model weights are excluded from Git by default. See the root README for the pinned download and verification command.
